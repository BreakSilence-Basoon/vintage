# Ledger 사실 입력 실험

이 패키지는 명시된 청구서 발행·결제·선지출 정산 사실의 입력 형식만 검증합니다. `validateLedgerFact`는 유효한 입력의 새 불변 객체를 반환하고, 유효하지 않으면 입력 내용을 포함하지 않는 일반 오류를 냅니다. 사실 사이를 연결하거나 실제 발생 여부를 확인하지 않습니다.

`amountMinor`는 최소 화폐 단위의 부호 있는 정수 문자열이며 계산하거나 숫자로 변환하지 않습니다. `currency`는 대문자 세 글자 형식만 확인하므로 실제 통화나 최소 단위 규칙을 검증하지 않습니다. 날짜는 `YYYY-MM-DD` 형식의 실제 달력 날짜입니다. ID와 금액 길이 제한은 이 실험의 기술적 입력 제한이며 업무·법률 정책이 아닙니다.

저장, 로그인, 접근 제어, 증빙, 중복 처리, 합계·환율·세금·정산 계산과 배포는 제공하지 않습니다. 실제 거래 데이터를 사용하면 안 됩니다. 범위와 다음 검증 조건은 [Ledger 공개 준비](../../docs/ledger-scope.md)를 참조하세요.
