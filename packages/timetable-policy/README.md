# Timetable 권한 규칙 준비

근무표 앱을 분리하기 위한 작은 **권한 판단 규칙**입니다. 아직 앱, 로그인, 데이터베이스, API 서버가 없으므로 이 패키지만으로는 설치하거나 실무에 사용할 수 없습니다.

계획상 같은 사업장에 속한 활성 직원은 근무표를 볼 수 있고, 일반 직원은 자기 출퇴근 기록만 볼 수 있습니다. 관리자는 같은 사업장의 출퇴근 기록을 보고 근무표 및 출퇴근 기록을 관리할 수 있습니다. 역할, 직원, 사업장, 대상 정보가 없거나 일치하지 않으면 거부합니다. 이 규칙은 실제 앱에 연결해 서버 요청마다 검증되기 전까지 보안 경계가 아닙니다.

서버는 로그인 제공자와 현재 직원 권한을 검증하고, 요청된 기록을 신뢰할 수 있는 저장소에서 직접 읽어 사업장과 소유자를 확인해야 합니다. 브라우저가 보내는 직원 ID나 역할을 그대로 신뢰하면 안 됩니다. 세션 종료·권한 회수, 기록별 접근, 사업장 분리, 감사 및 API 허용·거부 시험은 실제 서버를 구현할 때 별도로 필요합니다.

Node.js 24와 pnpm 10.11.0에서 `corepack pnpm --filter @vintage/timetable-policy test`로 이 규칙만 검사할 수 있습니다. 현재 시험은 가상의 식별자만 사용하며 로그인이나 실데이터 접근을 시험하지 않습니다.
