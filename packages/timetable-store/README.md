# Timetable 저장소 준비

직원 자격과 출퇴근 기록을 사업장 범위로 조회하기 위한 실험적 SQLite 저장소입니다. 이 패키지만으로 앱을 설치하거나 운영할 수는 없습니다. 테이블 초기화는 명시적으로 호출하며, 조회가 DB를 새로 만들거나 초기화하지 않습니다.

사업장과 직원의 관계를 외래 키로 확인하고, 직원 자격은 발급자와 주체를 함께 조회합니다. 출퇴근 기록은 사업장과 기록 ID를 함께 조회합니다. 데이터베이스 연결과 파일 위치·권한·암호화·백업은 호출자가 책임집니다. 로그인, 웹 기반 사용자·권한 관리와 기록 수정, 보존 기간은 아직 구현되지 않았습니다.

테스트에는 임시 파일과 가상 자료만 사용합니다. 운영에 쓰기 전에는 실제 로그인·서버 통합, 데이터 이전·마이그레이션, 동시성, 무결성, 백업·복구, 저장소 보호 및 실사용 검증이 필요합니다. `node:sqlite`는 Node.js 버전별 제공 상태를 확인해야 합니다.

실험용 DB 복사는 SQLite 백업 기능을 사용하고 임시 복사본의 무결성과 외래 키를 검사한 뒤 새 대상 파일을 만듭니다. 기존 파일을 덮어쓰지 않으며 대상 파일 시스템은 하드 링크를 지원해야 합니다. 복사 실패 시 대상 폴더에 `.vintage-copy-*` 임시 폴더가 남을 수 있고 이 폴더에도 민감한 데이터가 있을 수 있습니다. 무결성 통과는 실제 서비스 복구까지 검증됐다는 뜻이 아닙니다.

로컬 관리 명령은 새 일반 직원과 기록을 추가하거나 일반 직원 접근을 중지하고 같은 트랜잭션에 감사 행을 남깁니다. 이 명령은 DB 파일 쓰기 권한이 있는 로컬 운영자를 신뢰하며 웹 로그인 권한을 검증하지 않습니다. 감사에는 운영자 유형만 남으므로 개인별 책임 추적은 아직 지원하지 않습니다.

버전 3에서는 검증된 토큰의 주체를 현재 직원 명부와 대조해 활성 관리자일 때만 자신의 사업장 데이터를 변경하고, 같은 트랜잭션에 관리자 직원 ID를 기록합니다. 이 기록도 DB 쓰기 권한자가 직접 변경할 수 있으므로 변조 방지 감사 시스템은 아닙니다. 로그인 제공자 연결과 운영 검증 전에는 사용하지 않습니다.
