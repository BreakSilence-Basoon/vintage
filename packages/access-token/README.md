# 접근 토큰 검증 준비

OAuth 2.0 JWT 접근 토큰을 검증하는 실험적 구성 요소입니다. **로그인 화면, 완성된 인증 시스템이나 실행 가능한 앱이 아닙니다.** 서버 연결과 실제 로그인 제공자에 대한 검증 전에는 운영에 사용하지 않습니다.

신뢰하는 발급자와 API 대상, 허용된 클라이언트, 필요한 권한 범위 및 서명 키 확인 방법을 서버가 미리 설정해야 합니다. 이 구성 요소는 RS256 서명, 발급자, 대상, 만료·발급 시각, 토큰 종류, 필수 값과 설정된 클라이언트·권한 범위를 확인합니다. 결과에는 검증된 발급자·주체·클라이언트만 포함하고 토큰 자체는 남기지 않습니다. 토큰이 유효하더라도 서버는 현재 직원 자격과 대상 데이터의 권한을 매 요청마다 별도로 확인해야 합니다.

발급자 키는 신뢰할 수 있는 설정에서만 받아야 하며, 토큰이 제시한 주소를 신뢰하지 않습니다. 토큰 발급·갱신·취소, 로그인/로그아웃, 키 교체 및 운영 모니터링은 이 패키지에 포함되지 않습니다. 토큰 유효 시간 안의 즉시 취소는 이 검증만으로 확인되지 않으므로 운영 연결 시 별도 대책이 필요합니다. 지원 형식은 [RFC 9068](https://www.rfc-editor.org/rfc/rfc9068.html)의 JWT 접근 토큰 중 RS256이며, 불투명 토큰이나 모든 로그인 제공자를 지원한다고 보장하지 않습니다.

외부 의존성 `jose`는 MIT 라이선스로 배포됩니다. 이 저장소 자체의 라이선스는 아직 결정되지 않았습니다. 테스트는 메모리에서 일시적으로 만든 키와 가상 식별자만 사용합니다.
