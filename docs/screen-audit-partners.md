# Partners 화면별 대조

원본 화면과 공개판의 합성 흐름을 비교했습니다. 실제 협업처·협업 조건·판매·정산 정보와 계정 권한은 연결하지 않았습니다. 검사 근거는 [협업 화면](../apps/partners-web/src/partner-fixture-browser.test.mjs), [게스트·키보드 동작](../apps/partners-web/src/interaction-keyboard-browser.test.mjs), [기간 조회](../apps/partners-web/src/collaboration-browser.test.mjs)입니다.

| 화면 | 원본에서 확인한 구성·동작 | 공개판의 상태와 남은 차이 |
| --- | --- | --- |
| `/` | 협업 일정과 영역별 진입. | 합성 일정과 영역 이동 제공. 실제 일정·직원 권한은 미연결. |
| `/[area]` | 영역별 협업처·안내 진입. | 합성 영역과 협업처 이동 제공. 실제 협업 자료는 미연결. |
| `/[area]/[partner]` | 협업처 정산·상품·재고와 확정 내역 조회. | 합성 협업처·상품·재고·확정 내역과 쇼룸 계산기의 합성 조회 오류 제공 ([#325](https://github.com/BreakSilence-Basoon/vintad3e/pull/325)). 실제 조건·판매·정산 서버는 미연결. |
| `/[area]/[partner]/sign-in`, `/[area]/[partner]/guest` | 협업처별 게스트 로그인과 해당 협업처의 읽기 화면. | 합성 게스트 로그인·읽기와 다른 협업처 접근 거부 제공. 실제 계정·권한 설정은 미연결. |
| `/proj-bedroom/partner-01/settlement` | 쇼룸 협업 정산 기간 조회, 금액 요약·판매 내역과 조회 오류 안내에 대응. | 합성 기간 입력·요약·판매 표, 잘못된 기간 및 조회 오류 안내 제공. 실제 권한·판매·정산과 서버는 미연결. 공개판의 협업처 주소는 합성 이름을 사용. |
| `/accounts` | 직원 접근 확인, 이메일·협업 선택과 비활성 등록 단추. | 합성 로그인·선택과 비활성 단추 제공. 실제 계정 등록은 미연결. |
| `/guide/dj`, `/guide/dj/[slug]` | DJ 안내와 상세 경로·언어 이동, 상세에서 안내로 복귀. | 합성 안내의 한국어·영어, 두 장르 이동·복귀와 없는 상세의 404를 PC·모바일 폭에서 검사. 실제 사진·영상·협업 조건은 제외하며 세부 내용은 추가 대조 필요. |
| `/proj-bedroom/guide`, `/proj-bedroom/guide/[language]` | 작가 안내의 언어 이동·펼침·복사·이미지 확대. | 합성 안내의 언어 이동·펼침 유지·복사와 실패·이미지 확대 검사를 [#324](https://github.com/BreakSilence-Basoon/vintad3e/pull/324)에 추가. 실제 사진·영상·협업 조건은 제외하며 세부 내용은 추가 대조 필요. |
| `/sign-in` | 직원 로그인·로그인 화면 보기·복귀와 인증 오류 안내. | 합성 로그인·화면 보기·복귀와 원본 오류 문구 제공. 실제 인증 오류와 권한 판정은 미연결. |
| `/auth/session-resume` | 안전한 주소를 보존해 세션 갱신 뒤 재인증으로 이동. | 합성 세션과 로그인 복귀 제공. 실제 갱신은 미연결. |

실제 회사의 개인정보처리방침은 옮기지 않으며 각 가게가 직접 준비합니다. 위 표의 미대조 항목과 실제 서버의 권한·오류 분기는 원본과 일치한다고 판단할 수 없습니다.
