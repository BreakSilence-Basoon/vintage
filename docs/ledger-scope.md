# Ledger 공개 준비 범위

검토일: 2026-11-12. 작은 사업장이 자신의 업무 방식에 맞게 독립적으로 설치하는 도구를 준비합니다. 실제 설치 가능한 앱이나 회계·세무 서비스를 제공한다는 뜻은 아닙니다. 다른 가게와 인프라를 공유하는 서비스는 설계하거나 검증하지 않았습니다.

## 우선 다룰 문제

청구서, 영수증, 거래명세서 같은 증빙을 사업장이 한곳에서 살피고 필요한 사실을 확인할 수 있도록 준비합니다. 청구서가 발행된 사실, 실제 결제된 사실, 직원에게 선지출을 돌려준 사실은 서로 다릅니다. 하나만 확인됐다고 다른 사실이 자동으로 성립하는 것은 아닙니다. 수집한 문서와 사람이 확인한 내용을 구분하고, 확인되지 않은 내용을 결제 완료나 정산 완료로 표시하지 않아야 합니다.

각 사업장의 수집 대상과 권한, 결제 수단, 처리 방식은 다를 수 있습니다. 공급자 계정 연결이나 이메일 수집은 권한, 사용 조건과 개인정보 보호를 확인한 뒤 각각 구현해야 합니다. 결제 실행, 세금 계산, 환율 변환, 회계 분개와 자동 정산은 결정하거나 구현하지 않았습니다.

## 현재 구성

`@vintage/ledger-facts`는 사람이 명시한 세 종류의 사실을 구분해 입력 형태만 검사하는 실험용 구성 요소입니다. ID, 종류, 날짜, 통화 표시와 최소 단위 금액 정수 문자열을 보존하며, 청구서에서 결제를 추론하거나 금액을 합산하지 않습니다. 통화 표시는 영문 대문자 세 글자 형식만 검사하며 실제 통화 코드인지, 금액 단위가 해당 통화에 적합한지는 확인하지 않습니다. 금액의 부호·처리 방식과 실제 통화별 단위는 사업장과 연결 서비스의 정책에 따라 별도로 정하고 검증해야 합니다. 금액을 부동소수점 숫자로 변환하지 않는 방식은 [Stripe의 금액 단위 안내](https://docs.stripe.com/currencies)를 참고했으며 모든 서비스가 같은 형식이라는 뜻은 아닙니다.

별도의 [`@vintage/ledger-store`](../packages/ledger-store/README.md)는 신뢰된 서버 내부에서 사실을 저장·정정하고 같은 작업 ID의 재시도 중복을 막는 실험입니다. 정정 전후 내용이 같은 트랜잭션에 남지만 DB 쓰기 권한자가 바꿀 수 있습니다. 서로 다른 ID로 같은 사실을 등록하는 중복은 찾지 못하며, 호출자가 현재 권한을 검증해야 합니다.

문서 업로드·원본 보관, 자료 출처와 무결성 확인, 문서와 사실의 연결, 승인, 사업장 격리 또는 접근 권한은 없습니다. 정산 사실이 누구의 어떤 결제와 연결되는지 검증하지도 않습니다. 입력이 형식에 맞아도 실제로 발생한 사실이거나 증빙으로 확인됐다는 뜻은 아닙니다. 실제 거래 정보를 넣거나 업무에 사용하면 안 됩니다.

## 다음 검증 조건

1. 각 사업장이 사용할 인증과 사업장별·사용자별 읽기/쓰기 권한을 정하고 모든 문서와 기록 요청에서 검증합니다. 식별자를 아는 것만으로 접근을 허용하지 않습니다. [OWASP 객체 권한 검사](https://owasp.org/www-project-web-security-testing-guide/latest/4-Web_Application_Security_Testing/12-API_Testing/02-API_Broken_Object_Level_Authorization/)
2. 원본은 접근이 통제된 저장소에 보관하고, 출처·무결성·중복 여부를 확인할 수 있어야 합니다. 실험용 Ledger DB 복사는 SQLite 무결성을 검사하고 별도 복구 준비는 수동 확인 전 쓰기를 차단합니다. 지정한 기준 DB와 차이 건수를 비교할 수 있지만 기준의 최신성이나 외부 처리 내역·실제 복구를 검증하지는 않습니다. 일반 복사에는 이 차단이 추가되지 않습니다. 문서 등록과 관련 사실 저장의 실패·재시도, 백업·복원 및 접근 취소를 가상 자료로 시험합니다.
3. 직원 선지출과 실제 정산을 연결하려면 현재 권한, 해당 직원과 원래 결제의 관계, 증빙 확인, 정정·취소 정책을 명확히 하고 시험해야 합니다. 규칙을 정하기 전 자동 처리하지 않습니다.
4. 실제 인증 제공자, 암호화 전송, 보관 기간, 비용, 설치·복구 절차와 실사용을 확인합니다. 화면과 실제 서비스 연결은 별도 작업입니다.
